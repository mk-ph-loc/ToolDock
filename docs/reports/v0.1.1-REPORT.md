# Αναφορά v0.1.1 — 2026-10-28
Στόχος: διορθωτική έκδοση για δύο οθόνες. Αποτέλεσμα: υλοποιημένο πακέτο ενημέρωσης, εκκρεμεί δοκιμή Windows.
## Διαφορές που επιβεβαιώθηκαν στο GitHub
- shell.py: προστέθηκε το standard εικονίδιο tray από τον χρήστη.
- quick_actions/plugin.py: constructor με config=None.
- quick_actions/__main_widget.py: Browser με webbrowser.open Google.
Αυτές οι διορθώσεις διατηρούνται. Δεν έγινε γενικός έλεγχος κάθε αρχείου/ιστορικού του repo.
## Νέα
- Πρώτη αναβάθμιση σε floating, κανονική μπάρα τίτλου.
- Ορατά επιλογή dock, always-on-top, Ρυθμίσεις, Έξοδος.
- Dock στην οθόνη του κέντρου του παραθύρου· εξωτερικό frame εντός availableGeometry.
- Αποθήκευση θέσης/μεγέθους/οθόνης· επαναφορά μετά από αλλαγή διάταξης.
- Package script χωρίς δεδομένα/egg-info· release με ελέγχους κωδικών εξόδου.
## Έλεγχοι
7 νέοι έλεγχοι placement εκτελούνται ανεξάρτητα από Qt. Το πλήρες τοπικό suite εκτελείται από τον installer.
Δεν εκτελέστηκε GUI: το περιβάλλον δημιουργίας δεν διαθέτει PySide6/Windows.
## Περιορισμοί
Τα 3 modes και οι παλιές ελλείψεις του S1 δεν ολοκληρώνονται εδώ. Δεν αλλάζει autostart ή αποθήκευση σημειώσεων.
Dock δεν δεσμεύει χώρο σαν Windows taskbar/AppBar. Αν μη υποβλημένο κείμενο υπάρχει, η Έξοδος δεν το αποθηκεύει.
Δεν έγινε commit/tag/push, ούτε εγγραφή docs στα Project Files.
